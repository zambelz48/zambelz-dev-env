---
description: Make a development plan
---

Let's have a discussion first; do not modify anything yet.

Make a plan for $ARGUMENTS. The plan is written for AI agents, not for humans:
comprehensive, compact and clear, never convoluted, and without sacrificing
clarity or quality.

1. Before proposing anything, find up-to-date information with `context7` or
   web fetch, for the versions this repository pins. This is mandatory.
2. Propose the plan and wait for approval. Work in this session; plan for
   subagents only when the user asks for them in their own words.
3. Once the proposal is approved, write the plan to `dev-plan/` through the
   `create-dev-plan` skill, with a checkbox for every task, ticked with `x`
   when the task is done.
